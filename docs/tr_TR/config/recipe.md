# Rezepte

Pumpkin ermöglicht die Konfiguration, wie Rezepte an Clients für das Rezeptbuch gesendet werden.

## Rezepte konfigurieren

#### `send_recipes`: Boolean

Ob Rezepte an Clients gesendet werden, was das Rezeptbuch aktiviert.

:::code-group

```toml [pumpkin.toml] {2}
[recipe]
send_recipes = true
```

:::

## Standardkonfiguration

:::code-group

```toml [pumpkin.toml]
[recipe]
send_recipes = true
```

:::
