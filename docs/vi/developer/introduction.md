# Giới thiệu

Chào mừng bạn đến với Tài liệu Pumpkin!

Dù bạn là nhà phát triển nội bộ của Pumpkin hay đang làm việc với một plugin của Pumpkin, tài liệu này chính là nguồn tài nguyên dành cho bạn về mọi thứ liên quan đến Pumpkin.

## Phát triển Plugin

Để có cấu trúc tài liệu tốt hơn, tài liệu phát triển plugin đã được chuyển sang một [danh mục riêng](/plugin-dev/introduction).
