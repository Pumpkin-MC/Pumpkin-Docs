# Phát triển Plugin cho Pumpkin

::: warning
Pumpkin Plugin API hiện vẫn đang ở giai đoạn đầu của quá trình phát triển và có thể thay đổi bất cứ lúc nào.
Nếu bạn gặp bất kỳ vấn đề nào, vui lòng liên hệ qua [máy chủ Discord của chúng tôi](https://discord.gg/aaNuD6rFEe).
:::

Pumpkin Plugin API lấy cảm hứng từ plugin API Spigot/Bukkit ở nhiều khía cạnh,
vì vậy nếu bạn có kinh nghiệm trước đó với các nền tảng này và có kinh nghiệm phát triển bằng Rust, Python, C#, Go, C, Kotlin, D, Zig, hoặc TypeScript,
bạn sẽ dễ dàng viết plugin cho Pumpkin. :smile:

* [Rust API](https://github.com/Pumpkin-MC/Pumpkin)
* [Python API](https://github.com/Pumpkin-MC/pumpkin-api-py)
* [C# API](https://github.com/Pumpkin-MC/pumpkin-api-cs)
* [Go API](https://github.com/Pumpkin-MC/pumpkin-api-go)
* [C API](https://github.com/Pumpkin-MC/pumpkin-api-c)
* [Kotlin API](https://github.com/Pumpkin-MC/pumpkin-api-kt)
* [D API](https://github.com/Pumpkin-MC/pumpkin-api-d)
* [Zig API](https://github.com/Pumpkin-MC/pumpkin-api-zig)
* [TypeScript API](https://github.com/Pumpkin-MC/pumpkin-api-ts)
