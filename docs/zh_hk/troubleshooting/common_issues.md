# 常見問題

1. ## 無法驗證用戶名稱

    **問題:** 一些玩家報告在登入伺服器時遇到問題，包括遇到"無法驗證用戶名稱"的錯誤。

    **原因:** 這與身份驗證有關，通常與 `prevent_proxy_connections` 設定有關。

    **解決方法:** 在 `pumpkin.toml` 的 `[networking.java.authentication]` 下停用 `prevent_proxy_connections`。

2. ## 無法使用 0.0.0.0 連線到伺服器

    **問題:** 在本地電腦上執行伺服器的玩家在輸入 `0.0.0.0` 或 `0.0.0.0:25565` 時無法連線（例如遇到“Connection refused”錯誤）。

    **原因:** 在 `pumpkin.toml` 中，`0.0.0.0` 指示 Pumpkin 監聽所有本地網絡界面。這是伺服器的綁定位址，並不是客戶端可以連線的有效目標位址。

    **解決方法:**
    - 如果在**同一臺電腦**上連線，請在 Minecraft 客戶端中輸入 `localhost` 或 `127.0.0.1`。
    - 如果在**同一區域網（LAN）中的其他裝置**上連線，請使用主機的區域網 IP 位址（例如 `192.168.x.x`）。
    - 如果透過**網際網絡**連線，其他玩家必須使用你的公網 IP 位址或域名（並在路由器上轉發端口 `25565`）。
