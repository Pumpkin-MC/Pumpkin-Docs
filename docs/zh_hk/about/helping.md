# 幫助 Pumpkin 併為其捐贈

感謝你有興趣支援 Pumpkin！無論你是開發者、伺服器管理員還是 Minecraft 愛好者，都可以透過多種方式提供幫助。

---

## 1. 報告問題與提出功能建議

如果你在使用 Pumpkin 時遇到缺陷、崩潰或異常行為，建立 GitHub Issue 有助於我們快速跟蹤並解決問題。

- **檢查現有 Issue**：建立新工單前，請先搜尋 [Pumpkin GitHub Issues](https://github.com/Pumpkin-MC/Pumpkin/issues)，避免重複。
- **提供復現步驟**：附上清晰的步驟、伺服器日誌、預期行為與實際行為，以及系統詳細資訊。
- **使用 Issue 模板**：在 GitHub 上選擇合適的 Issue 模板（缺陷報告或功能請求）。

---

## 2. 程式碼與文件 Pull Request

我們歡迎程式碼貢獻、文件更新和缺陷修復！

有關程式碼貢獻，請閱讀專門的[貢獻指南](/zh_hk/developer/contributing)，瞭解如何設定環境、反編譯 Minecraft 邏輯以及提交 Pull Request 的完整說明。

> [!IMPORTANT] 程式碼規範
> 為 Pumpkin 貢獻程式碼時，請遵守我們的項目規範：
> - **遵循 Rust 格式化與靜態檢查規範**：提交 PR 前執行 `cargo fmt` 和 `cargo clippy`。
> - **遵守架構規則**：遵循現有的模組化結構和非同步程式設計實踐。
> - **保持提交與 PR 整潔**：讓 Pull Request 專注於單一主題，並使用清晰的提交資訊。
> - **討論重大更改**：在著手開發重大功能或重寫架構之前，請建立 GitHub Discussion/Issue，或在[我們的 Discord 伺服器](https://discord.gg/RNm224ZsDq)中與維護者討論。

---

## 3. 資金支援與捐贈

維護和改進高效能 Minecraft 伺服器軟件需要持續投入精力和資源。如果你希望為 Pumpkin 的開發提供資金支援：

- **捐贈**：請造訪我們的官方捐贈頁面 [pumpkinmc.org/donate](https://pumpkinmc.org/donate)，檢視資助方式。
- **伺服器基礎設施**：你也可以透過提供基準測試環境、硬件託管或測試基礎設施來提供幫助。

---

## 4. 社群與支援

加入我們的社群，幫助解答用戶問題、測試預發布功能並討論想法：

- **Discord 社群**：[加入 Pumpkin Discord](https://discord.gg/RNm224ZsDq)
- **GitHub 討論**：在 [Pumpkin GitHub Discussions](https://github.com/Pumpkin-MC/Pumpkin/discussions) 上分享反饋和想法
