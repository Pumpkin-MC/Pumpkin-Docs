# 配置

Pumpkin 提供了强大的配置系统，允许您在不依赖外部插件的情况下自定义服务器行为的各个方面。这为服务器的运行提供了灵活性和控制力。

## 配置文件

Pumpkin 使用单一的配置文件：

- `pumpkin.toml`：主配置文件，包含从基本网络设置到高级功能的所有服务器配置

当 Pumpkin 首次启动时，会在工作目录中生成带有默认值的 `pumpkin.toml` 文件。您可以在首次运行之前或之后编辑该文件。缺失的字段会在启动时自动填充默认值。

## 结构

配置按以下部分组织：

- **顶级字段**：核心设置，如版本支持、地址、种子、玩家限制、难度和游戏规则
- **`[logging]`**：日志输出和格式化
- **`[resource_pack]`**：Java 和 Bedrock 的资源包配置
- **`[world]`**：世界生成、区块存储、光照和自动保存
- **`[networking]`**：认证、压缩、代理、查询、RCON 和局域网广播
- **`[commands]`**：命令系统
- **`[chat]`**：聊天消息格式
- **`[pvp]`**：PvP 规则和机制
- **`[server_links]`**：向客户端显示的链接
- **`[player_data]`**：玩家数据持久化
- **`[fun]`**：实验性功能
- **`[recipe]`**：配方书配置
- **`[plugins]`**：插件权限设置

## 服务器版本

Pumpkin 旨在支持最新的 Minecraft 版本。如果您想为其他版本托管 Pumpkin 服务器，可以使用 [ViaProxy](https://github.com/ViaVersion/ViaProxy) 项目。

- 请确保允许代理连接。
- Pumpkin 与 ViaProxy 没有任何关联；请勿提交与其代码相关的问题。此外，这是一个第三方代理，Pumpkin 不对其好坏承担任何责任。

### 主要功能

- 广泛自定义：配置服务器设置、玩家行为、世界生成等。
- 性能优化：通过配置调整优化服务器性能。
- 无插件自定义：无需额外插件即可实现所需的更改。
