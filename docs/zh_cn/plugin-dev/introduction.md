# Pumpkin 插件开发

::: warning 警告
Pumpkin 插件 API 仍处于非常早期的开发阶段，可能随时会发生变化。
如果您遇到任何问题，请在我们的 [Discord](https://discord.gg/aaNuD6rFEe) 上联系我们。
:::

Pumpkin 插件 API 在很多方面借鉴了 Spigot/Bukkit 插件 API 的设计，
因此如果您之前有使用这些 API 的经验，
并且熟悉 Rust、Python、C#、Go 或 C 开发，那么为 Pumpkin 编写插件对您来说应该会相当轻松。:smile:

* [Rust API](https://github.com/Pumpkin-MC/Pumpkin)
* [Python API](https://github.com/Pumpkin-MC/pumpkin-python)
* [C# API](https://github.com/Pumpkin-MC/pumpkin-api-cs)
* [Go API](https://github.com/Pumpkin-MC/pumpkin-api-go)
* [C API](https://github.com/Pumpkin-MC/pumpkin-api-c)
