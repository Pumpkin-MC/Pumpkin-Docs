# Helfen & Spenden an Pumpkin

Vielen Dank für Ihr Interesse an der Unterstützung von Pumpkin! Egal, ob Sie Entwickler, Serveradministrator oder Minecraft-Enthusiast sind, es gibt viele Möglichkeiten, wie Sie helfen können.

---

## 1. Fehler melden & Funktionsvorschläge

Wenn Sie Fehler, Abstürze oder unerwartetes Verhalten bei der Verwendung von Pumpkin feststellen, hilft uns das Öffnen eines GitHub-Issues, Probleme schnell zu verfolgen und zu beheben.
- **Bestehende Issues prüfen**: Durchsuchen Sie [Pumpkin GitHub Issues](https://github.com/Pumpkin-MC/Pumpkin/issues), bevor Sie ein neues Ticket eröffnen.
- **Reproduktionsschritte angeben**: Geben Sie klare Schritte, Serverprotokolle und Systemdetails an.
- **Issue-Vorlagen verwenden**: Wählen Sie die entsprechende Issue-Vorlage auf GitHub aus.

---

## 2. Code- & Dokumentations-Pull-Requests

Wir freuen uns über Code-Beiträge, Dokumentationsaktualisierungen und Fehlerbehebungen!
Für Code-Beiträge lesen Sie bitte unseren [Beitragsleitfaden](/developer/contributing).
> [!IMPORTANT] Code-Richtlinien
> - **Rust-Formatierung & Linting befolgen**: Führen Sie `cargo fmt` und `cargo clippy` aus.
> - **Architekturregeln respektieren**: Befolgen Sie bestehende modulare Strukturen.
> - **Saubere Commits & PRs**: Halten Sie Pull-Requests auf ein einzelnes Thema fokussiert.
> - **Große Änderungen besprechen**: Besprechen Sie sich auf [Discord](https://discord.gg/RNm224ZsDq).

---

## 3. Finanzielle Unterstützung & Spenden

Die Pflege einer hochleistungsfähigen Minecraft-Server-Software erfordert viel Mühe und Ressourcen.
- **Sponsoring & Spenden**: Sehen Sie sich unsere Finanzierungsoptionen auf [GitHub Sponsors](https://github.com/sponsors/Pumpkin-MC) oder auf unserer offiziellen Website [pumpkinmc.org](https://pumpkinmc.org/) an.
- **Server-Infrastruktur**: Sie können auch durch die Bereitstellung von Testumgebungen helfen.

---

## 4. Community & Support

- **Discord-Community**: [Treten Sie dem Pumpkin-Discord bei](https://discord.gg/RNm224ZsDq)
- **GitHub-Diskussionen**: Teilen Sie Feedback auf [Pumpkin GitHub Discussions](https://github.com/Pumpkin-MC/Pumpkin/discussions)
