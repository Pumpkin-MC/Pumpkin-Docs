# Pumpkinへのヘルプと寄付

Pumpkinのサポートにご関心をお寄せいただきありがとうございます！開発者、サーバー管理者、Minecraft愛好家のいずれであっても、役立つ方法はたくさんあります。

---

## 1. 問題の報告と機能の提案

Pumpkinの使用中にバグ、クラッシュ、または予期しない動作が発生した場合は、GitHubのissueを開くと、問題の追跡と解決に役立ちます。
- **既存のissueを確認する**: 重複を避けるために[Pumpkin GitHub Issues](https://github.com/Pumpkin-MC/Pumpkin/issues)を検索してください。
- **再現手順を提供する**: 明確な手順、サーバーログ、システム要件を含めてください。
- **issueテンプレートを使用する**: 適切なテンプレートを選択してください。

---

## 2. コードとドキュメントのPull Request

コードへの貢献、ドキュメントの更新、バグ修正を歓迎します！
コードの貢献については、[貢献ガイド](/developer/contributing)をお読みください。
> [!IMPORTANT] コードのガイドライン
> - **RustのフォーマットとLintに従う**: `cargo fmt`と`cargo clippy`を実行してください。
> - **アーキテクチャのルールを尊重する**: 既存のモジュール構造に従ってください。
> - **クリーンなコミットとPR**: PRは1つのトピックに焦点を当ててください。
> - **大きな変更について議論する**: [Discord](https://discord.gg/RNm224ZsDq)で話し合ってください。

---

## 3. 財政的支援と寄付

高性能なMinecraftサーバーソフトウェアの維持には多大な労力が必要です。
- **寄付**: [pumpkinmc.org/donate](https://pumpkinmc.org/donate) の公式寄付ページで資金提供オプションを確認してください。
- **サーバーインフラ**: テスト環境を提供することでも貢献できます。
