# サーバー管理の概要

Pumpkin サーバー管理者のための**管理者セクション**へようこそ。Pumpkin は Rust で書かれた高性能マルチスレッド Minecraft サーバーであり、最小限のリソース消費で膨大なプレイヤー数をサポートできるように設計されています。

---

## サーバー管理者向けの主な機能

- **高度なマルチスレッド化**: 最新のマルチコアプロセッサ向けにゼロから設計されています。
- **WASM プラグインアーキテクチャ**: JVM のオーバーヘッドなしで、Rust、Python、Kotlin、C#、Go、C による安全でサンドボックス化されたプラグイン実行が可能です。
- **ネイティブなクロスプロキシサポート**: Velocity、BungeeCord、最新のプロキシ転送を標準でサポートしています。
- **TOML ベースの設定**: `pumpkin.toml` および機能ごとの TOML 設定ファイルによる、クリーンで人間が読みやすい設定です。
