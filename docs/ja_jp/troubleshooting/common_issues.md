# よくある問題

1. ## ユーザー名の検証に失敗

    **問題:** 一部のプレイヤーがサーバーへのログインに問題があり、「Failed to verify username」エラーに遭遇したと報告しています。

    **原因:** これは認証に関連しており、通常は `prevent_proxy_connections` 設定に関係しています。

    **修正:** `pumpkin.toml` で `prevent_proxy_connections` を無効にしてください。

2. ## 0.0.0.0 を使用して接続できない

    **問題:** 自身のPCでサーバーを実行しているプレイヤーが、`0.0.0.0` または `0.0.0.0:25565` を入力すると接続できません（例: 「Connection refused」エラー）。

    **原因:** `pumpkin.toml` において `0.0.0.0` は、Pumpkin がすべてのローカルネットワークインターフェースでリッスンすることを意味します。これはサーバー側のバインドアドレスであり、Minecraft クライアントが接続するための有効な宛先アドレスではありません。

    **修正:**
    - **同じPC**から接続する場合は、Minecraft クライアントで `localhost` または `127.0.0.1` を入力してください。
    - **同じローカルネットワーク（LAN）上の別のデバイス**から接続する場合は、ホストマシンのローカルIPアドレス（例: `192.168.x.x`）を使用してください。
    - **インターネット経由**で接続する場合、他のプレイヤーはあなたのグローバルIPアドレスまたはドメイン名を使用する必要があります（ルーターのポート開放が必要です）。
