## Operation Details

### `i18n.translate` {#operation-i18n-translate}

```text
translate: func(key: string, locale: locale) -> string;
```

Retrieves a translated string from the host.

# Arguments

# Returns
The localized string, falling back to English or the key itself.

**Parameters**

| Name | WIT type | Description |
| --- | --- | --- |
| `key` | `string` | The namespaced translation key (e.g. `pumpkin:my_key`). |
| `locale` | `locale` | The target locale. |

**Returns:** `string`

### `i18n.load-translations` {#operation-i18n-load-translations}

```text
load-translations: func(namespace: string, json: string, locale: locale);
```

Loads custom translations from a JSON string.

# Arguments

**Parameters**

| Name | WIT type | Description |
| --- | --- | --- |
| `namespace` | `string` | The namespace to associate these keys with. |
| `json` | `string` | A JSON string containing a flat map of translations. |
| `locale` | `locale` | The target locale for these translations. |
