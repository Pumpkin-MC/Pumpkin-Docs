# Recipe

Pumpkin allows you to configure how recipes are sent to clients for the recipe book.

## Configuring Recipes

#### `send_recipes`: Boolean

Whether recipes are sent to clients, enabling the recipe book.

:::code-group

```toml [pumpkin.toml] {2}
[recipe]
send_recipes = true
```

:::

## Default Config

:::code-group

```toml [pumpkin.toml]
[recipe]
send_recipes = true
```

:::
