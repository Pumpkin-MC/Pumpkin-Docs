# Fun

Let's face it, the only reason we play this game is because of fun.

## Configuring Fun

#### `april_fools`: Boolean

Whether April Fools features are enabled.

:::code-group

```toml [pumpkin.toml] {2}
[fun]
april_fools = true
```

:::

## Default Config

:::code-group

```toml [pumpkin.toml]
[fun]
april_fools = true
```

:::
