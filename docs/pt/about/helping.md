# Ajudar e Doar para Pumpkin

Obrigado pelo seu interesse em apoiar o Pumpkin! Seja você um desenvolvedor, administrador de servidor ou entusiasta do Minecraft, existem muitas maneiras de ajudar.

---

## 1. Relatando Problemas e Sugestões de Recursos

Se você encontrar bugs, falhas ou comportamento inesperado ao usar o Pumpkin, abrir uma issue no GitHub nos ajuda a rastrear e resolver problemas rapidamente.
- **Verifique issues existentes**: Pesquise [Pumpkin GitHub Issues](https://github.com/Pumpkin-MC/Pumpkin/issues).
- **Forneça etapas de reprodução**: Inclua etapas claras, logs do servidor e detalhes do sistema.
- **Use modelos de issue**: Selecione o modelo apropriado no GitHub.

---

## 2. Pull Requests de Código e Documentação

Agradecemos contribuições de código, atualizações de documentação e correções de bugs!
Para contribuições de código, leia nosso [Guia de Contribuição](/developer/contributing).
> [!IMPORTANT] Diretrizes de Código
> - **Siga a Formatação e Linting do Rust**: Execute `cargo fmt` e `cargo clippy`.
> - **Respeite as Regras de Arquitetura**: Siga a estrutura modular existente.
> - **Commits e PRs Limpos**: Mantenha os Pull Requests focados em um único tópico.
> - **Discuta Grandes Mudanças**: Converse no [Discord](https://discord.gg/RNm224ZsDq).

---

## 3. Suporte Financeiro e Doações

Manter um software de servidor Minecraft de alto desempenho requer muito esforço.
- **Doações**: Confira nossas opções de financiamento em nossa página oficial de doações [pumpkinmc.org/donate](https://pumpkinmc.org/donate).
- **Infraestrutura de Servidor**: Você também pode ajudar fornecendo ambientes de teste.

- **Comunidade Discord**: [Junte-se ao Pumpkin Discord](https://discord.gg/RNm224ZsDq)
